# Wayfinder Lab

The Lab is the safe place for ideas that are not yet Canon.

Use it for:

- Flower explorations
- alternative ontologies
- archetype systems
- Character mechanics
- astrology concepts
- experimental domains
- agent behavior
- speculative UI models
- contradictory approaches worth testing

## Rule

A Lab idea may inspire implementation experiments, but core architecture must not silently depend on it.

Promotion path:

`LAB → CANDIDATE → CANON`

Promotion should include evidence, trade-offs, and an ADR when architectural behavior changes.

The Lab exists so Wayfinder can stay imaginative without making every interesting thought foundational.
